# GTA VI Cover Art Maker — make.fun entry

Turn your photo into a Vice City poster. An offline canvas poster app: upload a photo (or use the built-in procedural sunset skyline), pick a colour grade and a panel layout, add a caption and the GTA VI title treatment, then export a 1080 × 1350 PNG. Nothing leaves the browser — no uploads, no network, no external assets.

## Run

Serve with `node serve.ts`, then open http://localhost:8080. No build step, no server beyond that, no network needed. Click "Use sample photo" or drop your own photo, pick a preset and layout, then "Export PNG".
